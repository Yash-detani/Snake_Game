</p>

<p align="center">
  A lightweight terminal-based Snake Game featuring real-time keyboard input,
  dynamic snake growth, configurable grid dimensions, difficulty levels,
  and collision-based game-over mechanics.
</p>

---

## ✨ Project Highlights

<table>
  <tr>
    <td>🎯 <strong>Real-Time Controls</strong></td>
    <td>Move instantly using W, A, S, and D without pressing Enter.</td>
  </tr>
  <tr>
    <td>🍎 <strong>Dynamic Food</strong></td>
    <td>Collect randomly generated food to increase your score and snake length.</td>
  </tr>
  <tr>
    <td>🧱 <strong>Collision Detection</strong></td>
    <td>Detects boundary collisions and collisions with the snake’s own body.</td>
  </tr>
  <tr>
    <td>⚙️ <strong>Custom Configuration</strong></td>
    <td>Choose the player name, grid size, and difficulty level.</td>
  </tr>
  <tr>
    <td>🔁 <strong>Restart Support</strong></td>
    <td>Start a new round or quit after the game ends.</td>
  </tr>
  <tr>
    <td>🐧 <strong>Linux Compatible</strong></td>
    <td>Uses Linux terminal handling through <code>termios</code> and <code>unistd.h</code>.</td>
  </tr>
</table>

## 📸 Gameplay Preview

> 🖥️ SnakeX runs directly inside a Linux terminal or GDB terminal.

```text
Player: Yash | Score: 30 | Grid: 20x20
----------------------
|                  # |
|                    |
|          Ooo       |
|                    |
|                    |
----------------------

Controls:
W → Up
A → Left
S → Down
D → Right
X → Quit
```
